# Web-OS
### we r thinking of naming it LarpOS


-  this is a project for thirdspace.hackclub.com 
-  we are a team of 3 friends and are contributing to the project equally
-  theres no specific theme that we opted for but my frens liked the macOS theme kinda so went with its style

- we decided to make a WebOs because um its like the thing we needed the mosttt maybe , and becuz im tired of dual booting jus for dat linux like feel 
-  we come accross new devices and new locations everyday , and confirguring them to ur needs , a webOS gets rid of all those problems cuz all u hab to do is use a browser go to the deployed url and voila its like ur back home 
-  yeahh...... we havent added any backend or auth yet 
- but don be sed we plan on doing so , cuz itd be so nice to have ur personal operating system n work environment just hosted on the internet that ucan access from different devices and different places
- development is complete for now.

## Features: 

- There are manyyy , you can Even find a detailed tutorial when u open it for the first time , or if u miss it play it from the settings
- most of it behaves like a normal OS expect ofc with the limitations of a WebOS
- there r some shortcut keys , some usefull apps 
- customization options etc.
- u can import or export ur data too
